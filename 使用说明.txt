时线棋局：下载后使用说明（Windows 10/11 x64）
================================================

一、第一次启动
1. 右键下载的 ZIP，选择“全部解压”。不要在压缩包内直接双击。
2. 打开解压后的文件夹，确认有“本地.bat”“远程.bat”和 scripts 文件夹。
   不要只把两个启动文件拖到其他目录。中文和空格路径可以使用。
   路径尽量短，例如 C:\Games\5DChess；需要有写入权限。
3. 双击“本地”或“远程”。无需先安装 Python、Git、PowerShell 7 或数据库。
4. 首次启动需要联网：自动准备项目专用 Python 和依赖，请等待窗口提示。
   远程模式还会下载 Cloudflare。不会修改系统 PATH，不要求管理员权限。
5. 准备完成后会自动打开浏览器；若未打开，请复制启动窗口显示的网址。
   首次下载失败不会继续启动半成品，按提示检查网络后重新双击即可。

二、选哪个启动文件
【本地.bat】
用于自己游玩、同屏双人和同一局域网联机。
自动打开本机地址，通常是 http://127.0.0.1:5050 。
首次依赖准备完成后，后续本地游玩可以离线启动。
局域网联机时，房主和对方都改用窗口列出的局域网地址，
例如 http://192.168.1.20:5050 ，再创建房间和复制邀请链接。
不要把 127.0.0.1 发给对方；0.0.0.0 是监听设置，不是访问网址。

【远程.bat】
用于双方不在同一局域网时联机，默认使用 HTTP/2 隧道。
只有房主需要下载并运行项目；对方只需浏览器。
等待“公网地址：https://……trycloudflare.com”出现，双方使用这个网址。
房主创建在线房间，然后复制页面中的邀请链接给对方。
对方打开链接并点击加入。6 位房间码只在该房主的网站中有效。
免费临时入口依赖 Cloudflare 和双方网络，不能保证始终可达或低延迟。

三、停止与切换
在启动窗口按 Ctrl+C，等待“关闭本地 Flask 服务”等提示后再关窗口。
若出现“终止批处理操作吗”，确认服务停止后输入 Y。
切换本地/远程前先停止原窗口。同一项目重复双击会被拦截。
请不要强制结束进程、直接关闭启动窗口，或在运行时移动项目文件夹。
仅关闭浏览器不会停止网站。房主电脑睡眠或断网会中断联机。

四、常见情况
• 端口被占用：自动从 5050 向上寻找空闲端口，以窗口显示的实际地址为准。
• 首次一直下载或报错：检查网络能否访问 api.nuget.org、pypi.org、
  files.pythonhosted.org；远程模式还需要 GitHub 和 Cloudflare。
  不需要反复重装，恢复网络后再次双击；安装日志位于 logs\launcher。
• 提示文件不完整：重新解压整个 ZIP，不要单独运行启动文件。
• 提示已有启动窗口：回到原窗口；停止后再启动另一模式。
• 防火墙提示：局域网联机可允许本项目 Python 在所用专用网络通信。
  启动器不会关闭防火墙或擅自修改规则。
• 没有自动打开浏览器：手动复制窗口里的实际网址。
• Cloudflare 失败：查看 logs\p2p 中窗口指明的日志。本地模式仍可单独用。
• 房间已过期/身份失效：联网心跳会持续续期，对局没有固定时长限制；
  离线 8 秒后暂停操作，额外保留 10 分钟供重连。保留原页面等待恢复。
  超过期限或重启服务后，房主可在本机页面点击“存档与回放”→“继续对局”。
  恢复到最后一次成功提交的行动，未提交走子需重走。
• 远程重启：临时网址通常会变化。先恢复存档，再发送新的公网网址和房间码。
  房主恢复时使用启动窗口里的 127.0.0.1 本机网址；对手仍使用公网网址加入。
  本机页面的“复制房间码”只复制房间码，不要把 127.0.0.1 发给对手。
• 自动存档失败：行动尚未提交。检查 saves 目录写入权限和磁盘空间后重试。
• 更新项目：先结束当前对局并停止服务，再使用新版本。不要边玩边覆盖。

五、文件与分发
本地.bat / 远程.bat：启动入口，请与 scripts、src 等目录保持在一起。
.runtime：自动下载的独立运行环境，可在停止后删除，之后启动会重新下载。
logs\launcher：安装和启动日志；logs\p2p：网站与隧道日志。
saves：在线棋局自动存档，每次成功提交行动后更新。新建房间保留旧存档。
在本机网址（127.0.0.1）的菜单点击“存档与回放”，选择一份存档：
• 继续对局：从最后已提交的行动恢复，生成新房间码；重新邀请对手加入。
• 观看回放：从开局逐手观看，可上一手、下一手、播放/暂停或跳转。
  回放不会修改原存档，也不需要对手在线；结束的棋局只能回放。
列表按保存时间排列，显示所有可读取的存档；不需要 SQL 或数据库服务。
存档不含玩家身份令牌。公网或局域网访客不能读取房主的存档列表。
旧 .5dpgn 棋谱可从“存档与回放”里的“其他棋谱（.5dpgn）”入口加载。
仅在线房间自动保存；同屏对弈和人机对弈不在本次自动存档范围内。
存档与 .runtime 分开；更新 ZIP 时，停止服务后把旧 saves 文件夹复制到新项目中。
请定期备份 saves，不要向对手分享整个运行目录；损坏存档会提示并保留原文件。

向别人分享项目时，推荐分享 GitHub Releases 中的 5DChess-Windows.zip。
下载地址：https://github.com/Polarzen/5Dchess/releases/latest
在该页面的 Assets 中选择 5DChess-Windows.zip。
源码包不含你的运行环境、日志和本地数据；对方首次运行会自动准备环境。
macOS、Linux、Windows ARM/32 位不适用这两个启动入口，请参考 README。
更多玩法、开发和命令行说明见 README.md 与 docs\guides\P2P_CLOUDFLARE.md。

运行组件来源与版本清单：scripts\p2p\python-runtime.json、cloudflared-release.json。
下载组件会核对固定 SHA-256；项目依赖由 pip 从 PyPI 安装。
