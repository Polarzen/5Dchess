会下国际象棋 · 只补上跨棋盘这一步

跨棋盘，怎么走？

把每张棋盘看成一个局面。棋子除了在盘内走，还能按自己的走法，走到另一张棋盘上。

1 选棋子，看各盘落点2 落到历史，才会分支3 走完后，手动提交

01 先读懂棋盘标题

L 是哪条线，T 是第几回合，白／黑是该棋盘轮到谁。 同一条线上，时间顺序是：

T0 · 白方→T0 · 黑方→T1 · 白方

跨时间“一步”指 T 相差 1，例如 T1 白方 → T0 白方；不是挪到紧挨着的黑方棋盘。跨线“一步”指 L 编号相差 1，例如 L0 → L+1；L−1 → L+1 算两步。

  • 从哪里走：从标为“可行动”的最新棋盘选自己的棋子。历史棋盘不能选子出发。
  • 走到哪里：看选中棋子后，各张棋盘上亮起的合法落点。目标必须已存在，且白方阶段对白方阶段、黑方阶段对黑方阶段。

02 用三枚熟悉的棋子，看懂跨线

原来的横、竖之外，多了时间和时间线两个方向。走法的形状仍由棋子决定，不是任意传送。

后、王、兵怎么跨？展开速查
后：选中的方向，走一样远。
可以同时改变横、竖、时间、时间线中的一到四个方向，改变的距离必须相等。比如跨一条线，同时向右一格、向前一格；不能跨一条线却横走两格。
王：每个选中的方向，都只走一步。
也能跨时间或跨线，但落子及提交都要满足王安全。跨棋盘没有王车易位。
兵：跨线前进，跨线加时间才吃子。
不吃子时保持格子和 T 不变：白兵走向更小的 L，黑兵走向更大的 L，目标要空。首次可沿这个方向走两步，中间棋盘和空格都要存在。
跨棋盘吃子时保持格子不变，沿自己的 L 前进方向走一步，同时 T 加一或减一；落点必须有敌子。兵不能只沿时间旅行，也不能把普通斜吃随意拼成其他跨盘走法。
回到过去时，落点也一定是原来的格子吗？

不一定。把上面例子的“跨一条线”换成“回到前一个 T”，走法同样成立：车 d4 → d4，象 d4 → e4，马 d4 → f4。象、马还有其他方向；这些只是帮助记忆的例子。

时间方向能指向更早或更晚，但目标必须已经存在；同一条线最新棋盘之后没有凭空可去的未来。不能落在己方棋子上，过去的自己也会占格。

03 看目标是不是历史，判断会不会分支

目标是另一条线的最新棋盘

两条线各往后走一步

出发棋盘生成“棋子已离开”的后继；目标棋盘生成“棋子已到达”的后继。不会额外开新线。

目标是已经有后继的历史棋盘

从那段过去，另开一条线

原历史和原来的后续都保留。棋子实际出现在新支线的后继棋盘，不是把旧历史改掉。

例如：车从 L0 · T1 白方的 d4 回到 L0 · T0 白方的空 d4，会在新支线的 T0 黑方后继中看到这枚车；原 L0 · T0 白方棋盘保持原样。

跳到很早的支线后，为什么暂时不能继续走？

只能从每条线自己的最新棋盘出发，不是只能操作时间最晚的那条线。点击“当前行动”里的棋盘按钮可以直接定位；点击历史棋盘后，也可以定位本线最新棋盘。

白棋跳过去后，新棋盘先轮到黑方；要等黑方在这张棋盘推进，白棋才会再次轮到行动。可选支线（规则中的“非活动线”）也能操作，只是不强制推进：若对手不在此走子，这里的棋子就可能一直等待。

一方比对手多开的第二条及后续支线会暂不参与当前时刻；对手创建更多支线后，它们可能加入。吃过去的棋子只改变新支线，不会删除原时间线上已经发生的后续。原线上的攻击仍需防守，不能用“回到过去吃掉它”来自动解除原线的将军。

04 落子后，再看红框和提交按钮

一次回合可能需要走多张棋盘。一手跨线也可能同时推进两张棋盘；新分支又可能带来新的红框。

每走一手重新看红框 → 完成必须推进的棋盘 → 保证所有己方王安全 → 点击“提交行动”。 提交成功，才真正交给对手。

按钮不可用时看“当前行动”面板：可能还有棋盘要走，也可能有王受到其他棋盘的攻击。没有红框不代表一定能提交。

速读和练习都不会改动真实对局。
