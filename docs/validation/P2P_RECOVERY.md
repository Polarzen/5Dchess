# 在线存档与恢复验收

日期：2026-10-12。范围：Windows、Python 3.11，单机多客户端、真实独立服务进程及浏览器。**尚未完成两台异地实体电脑的实测**；用户目前没有第二台电脑，本阶段先完成自动验证与测试说明。

## 已验证

- 完整 Python 测试：841 通过、2 跳过；包含 Windows 启动器、端口与安装防呆回归。三组 JavaScript 回归通过。
- 新建房间保存初始局面；走子不覆盖检查点；成功提交后更新存档。多时间线、同一行动多次走子、历史和回合状态可精确恢复。
- 模拟磁盘替换失败：旧存档字节不变，当前待提交行动不变，重试仅提交一次。初始写盘失败不会留下半个房间。
- 实际启动独立 Flask 进程，经 HTTP 创建双玩家、提交白方行动、执行未提交黑方走子，再强制终止进程；重启恢复后与白方已提交棋局一致，黑方重新加入并成功继续提交。
- 座位离线倒计时随心跳更新，即使棋局版本不变也会更新界面；短暂断网自动重连，超过保留期仍可从磁盘恢复。40 分钟模拟时间的心跳续期测试通过，不代表真实异地长局实测。
- 损坏存档、路径穿越、无效身份、旧提交请求、重复点击恢复和过时响应均有回归覆盖。远程来源、公网 Host、Cloudflare/代理转发以及跨站来源不能读取或恢复房主存档。
- 真实浏览器：菜单列出存档并恢复双时间线棋局；停止服务时显示自动重试和预计身份保留倒计时；服务重启后提示房主恢复，再次恢复成功。
- 新建房间保留其他存档；令牌不写入存档；发行打包器拒绝包含 `saves/` 的 ZIP。

## 两台异地电脑的人工步骤（待验收）

只在测试棋局进行；不要用正在玩的重要对局做断网或强制退出测试。双方记录版本号、浏览器、网络类型、步骤、耗时及结果即可，不分享身份令牌。

| 场景 | 操作 | 通过条件 |
| --- | --- | --- |
| 首次安装 | 房主在未安装项目环境的 Windows 64 位电脑解压发行 ZIP，双击 `远程.bat`；对手使用另一网络，只打开房主发来的公网网址 | 环境自动安装，页面可用；重复双击被拦截；对手无需下载项目 |
| 创建与加入 | 房主创建在线房间，发送公网网址和房间码；对手点击加入 | 双方执不同颜色，走子后提交，对方棋局一致；“已存档”行动数增长 |
| 长局 | 至少持续 60 分钟，包含跨时间线走子和多走子的行动 | 身份不会因对局时长失效；双方历史和当前轮次一致；存档持续更新 |
| 短时断网 | 对手断网 90 秒，保留页面；房主观察提示后恢复网络 | 8 秒后暂停对手离线操作，显示剩余保留时间；恢复后回到原颜色，棋局不丢失、不重复提交 |
| 超时离线 | 房主关闭浏览器超过 10 分 8 秒；再在本机网址打开页面 | 旧房间过期有恢复提示；房主从存档恢复，发送新房间码，对手重新加入后可继续 |
| 服务重启 | 确认已存档行动数，随后再走一步但不提交；房主停止服务并重新双击 `远程.bat` | 房主本机恢复后只有最后一次已提交状态；未提交走子回退；用当前公网网址和新房间码重新邀请成功 |
| 升级保留 | 停止服务，将旧项目 `saves` 复制到新 ZIP 解压目录 | 新版本列出旧存档，恢复后所有时间线和行动数一致 |
| 结束 | 房主启动窗口按 Ctrl+C | 网站和隧道停止；存档仍在，下次可以恢复 |

实际断网倒计时只是客户端估计，服务器仍是到期判定依据。Cloudflare 临时网址本身是否可用、异地延迟和对手网络防火墙仍须以上真实双机步骤验证。
