## 已完成

- 单元和集成：LLM 仅选择完整合法回合编号；规划不修改输入；单次落子路径只提交一次。覆盖初始局面、多必走棋盘、历史分支，以及无效编号、布尔编号、截断、非 JSON、缺字段回复。
- 失败处理：网络超时回退；每局请求数到顶后停止调用；仅一个候选不调用；优先避开第三次重复。上下文过大时不发请求。
- 网络：回环 HTTP 服务验证实际请求格式及认证头，401、429、302 不重试，不跟随重定向转发密钥。绝对等待期限结束后迟到响应不能操作棋局；全进程最多一个网络工作线程，未退出时直接本地回退。
- 配置：文件路径相对项目解析，环境变量覆盖；错误不回显密钥；公网接口必须 HTTPS；配置检查不调用模型。
- Web：公网 Host、Cloudflare/转发头、跨站请求、局域网访客不能启动或调用付费 AI。提取了与存档管理共用的本机访问检查，既有存档测试通过。
