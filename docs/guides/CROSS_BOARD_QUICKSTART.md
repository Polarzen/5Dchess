# 会下国际象棋？从跨棋盘开始

[游玩指南](PLAY.md) · [完整规则](../../规则.md)

只补上三件事：**棋子能换棋盘；落到历史才会分支；走完后要提交。** 网页主页和对局顶部的「跨棋盘速读」有车、象、马的对照图，也能直接进入对应练习。

## 先看标题，再选棋子

- **L 是哪条时间线，T 是第几回合。** 同线顺序是 `T0 白方 → T0 黑方 → T1 白方`。
- 从标为「可行动」的最新棋盘，选择自己的棋子。历史棋盘只能作为可能的落点，不能选子出发。
- 选中后看**各张棋盘上**亮起的合法落点。目标必须已存在，而且白方阶段对白方阶段、黑方阶段对黑方阶段。

跨时间一步，是 `T1 白方 → T0 白方` 这样的 T 相差 1，不是挪到旁边的黑方棋盘。跨线一步按 L 编号算：`L0 → L+1` 是一步，`L−1 → L+1` 是两步。

## 车、象、马：三个例子就能看出区别

假设两张棋盘都是 **T0 白方**，棋子从 **L0 的 d4** 出发，目标在 **L+1**：

| 棋子 | 目标格 | 怎么记 |
| --- | --- | --- |
| 车 | d4 | 只换一条线，格子不变：沿一个方向走 |
| 象 | e4 | 跨一条线＋横移一格：两个方向走一样远 |
| 马 | f4 | 跨一条线＋横移两格：仍是 2＋1 |

所以，**跨棋盘不一定落在原来的格子**。把例子中的「跨一条线」换成「回到前一个 T」，也是这三种棋子的走法：车保持 d4，象可到 e4，马可到 f4。这些只是示例，其他方向也可能合法。

图形合适还不够：目标不能有己方棋子，过去的自己也会占格；车、象、后的中间路径必须有棋盘且没有棋子阻挡。马可以跳过中间，但目标棋盘必须存在。所有走法仍需检查王安全，以游戏亮起的落点为准。

### 后、王、兵补充速查

- **后：**横、竖、时间、时间线中，可选一到四个方向一起改变，但改变的距离要相等。例如跨线一步、横移一步、纵移一步；不能跨线一步却横移两格。
- **王：**可选上述一到四个方向，每个都只走一步；仍须保证王安全。没有跨棋盘王车易位。
- **兵不吃子：**格子和 T 不变，沿时间线前进。白兵去更小的 L，黑兵去更大的 L，目标必须为空；首次可走两步，中间棋盘与空格也必须存在。
- **兵跨棋盘吃子：**保持原格子，沿自己的 L 前进方向一步，同时 T 加一或减一，落点必须有敌子。不能只沿时间走，也不能任意拼接普通斜吃。

时间方向可以往早或往晚，但只能落到已经存在的棋盘。同一条线最新棋盘之后，没有凭空可去的未来。

## 会不会产生新支线？只看目标是不是历史

**目标是另一条线的最新棋盘：**两条线各生成一个后继，一边是棋子离开后的局面，一边是棋子到达后的局面。不额外开新线。

**目标是已有后继的历史棋盘：**原历史和原来的后续都保留，另外从那段过去生成新支线。棋子真正落在**新支线的后继棋盘**上。

例如车从 `L0 · T1 白方 / d4` 回到 `L0 · T0 白方 / d4`（目标为空），会在新支线的 `T0 黑方` 后继中看到车。旧的 `L0 · T0 白方` 不被改写。

记住：**跨到另一条线，不等于一定新开一条线；回到历史也不等于撤销以前的棋。**

### 跳过去以后，为什么这个棋子动不了了？

“最新棋盘”指**每条线最右端的棋盘**，不是全局时间最晚的那条线。“当前行动”会列出本回合所有可操作棋盘，包括很早的可选支线，点击按钮即可定位。点击历史局面时，可以用“定位本线最新棋盘”回到能操作的位置。

白棋跳过去后，新棋盘先轮到黑方；黑方在此走一步，才又轮到白方。可选支线（规则中的非活动线）也允许走子，只是不强制推进。如果对手选择不在这条支线走，刚跳过去的棋子会继续等待；它不是因为时间太早而失效。

一方比对手多开的第二条及后续支线暂不参与当前时刻，对手开出更多支线后可能被激活。吃掉过去的兵或象，改变的是**新支线**；原线上的后续兵、象仍然存在，原线上的将军也不会自动消失。是否值得跨盘吃子，要看新局面能否形成威胁，以及留在其他棋盘上的王是否安全。

## 落子后，怎么结束自己的回合？

1. 重新看红框，完成目前必须推进的棋盘。
2. 确认所有己方王安全，包括其他棋盘上的威胁。
3. 点击「提交行动」，成功后才交给对手。

一手跨线可能同时推进两张棋盘，新分支也可能带来新的红框。不能只记「每张棋盘走一次」或「落下一枚棋子就换人」；每次落子后跟着最新红框和行动面板的提示走。

没有红框但仍不能提交时，先看行动面板是否提示王不安全。需要实际练习时，在网页速读说明中点击「亲手试这一步」或「试一次回到过去」；练习不会改变真实对局。
