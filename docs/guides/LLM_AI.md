# 在线 AI 对弈（DeepSeek 优先）

[文档导航](../README.md)

主页选择“在线 AI · DeepSeek / 自选模型”，可用语言模型代替固定三档 AI 的选招方式。现有离线 AI 继续保留，无需账户或费用。在线模式是实验功能，不保证比困难 AI 更强。

对局中点击“保存棋局”，存档写入项目 `saves/local`，不包含密钥。关闭前需手动保存；AI 思考时先等其走完。主页“存档与回放”可继续原来的 AI 对局或观看回放；继续在线 AI 对局需要本机有效配置，回放不需要密钥。

## 首次配置

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建 API 密钥，确认账户可调用 API。聊天网页的使用资格不代表有 API 额度。
2. 双击 `本地.bat`，在房主电脑通过启动窗口给出的 `http://127.0.0.1:端口` 打开游戏，选择“在线 AI · DeepSeek / 自选模型”。
3. 默认已选择 DeepSeek 并填好地址和模型。粘贴自己的密钥，点击“保存到本机”，无需手动创建文件。需要使用其他服务商时，选择“自定义兼容接口”，填写其地址、模型和对应密钥。
4. 可点击“测试连接（少量计费）”验证认证和回复格式，然后点击“开始在线 AI 对局”。保存和重新载入不调用模型；每次连接测试会发起一次小请求，可能计费，不计入任何对局的请求上限。

密钥默认遮罩，可临时显示刚输入的内容。保存或关闭后输入框清空；重新打开只显示“已保存”，不会返回旧密钥。修改其他设置时留空可保留旧密钥；切换接口地址时必须重新提供密钥，防止误发给另一家服务商。粘贴地址时会去掉两端空格、补全 HTTPS，并自动移除末尾重复的 `/chat/completions`。

网页会校验必填项、地址格式、网络等待 1–15 秒及每局请求上限 1–200 次。保存中禁止重复提交；保存失败保留原配置。多个窗口同时修改时会要求重新载入，避免覆盖较新的设置。重新载入会放弃当前未保存的输入。

配置保存在项目 `.runtime/llm.json`，不写入浏览器本地存储、棋谱、日志或发布包，也不会通过配置读取接口回显密钥。不要把自己的 `.runtime` 文件夹转发给别人。公开联机网址、局域网网址不能查看或修改配置、测试连接或调用此付费功能；请在房主电脑使用本机网址。

配置窗口顶部直接显示保存状态和房主电脑上的完整文件位置。点击“复制文件夹路径”，可在文件资源管理器地址栏粘贴定位；首次保存前文件尚未创建。对局中也可点击“在线 AI 设置与密钥”打开管理窗口。

- 更换：点击“更换密钥”，填写新密钥，再点击“保存修改”。保存失败时旧配置保留；可用“重新载入已保存设置”放弃尚未保存的修改。
- 删除：点击“删除密钥及配置”，阅读说明后再点“确认删除”。这会移除本机 `.runtime/llm.json`（包括接口和模型设置），不影响存档，不会替你撤销供应商平台的密钥。取消不会删除；文件损坏时也可使用此入口清理。
- 环境变量：窗口显示“环境变量覆盖 · 网页只读”时，更换和删除按钮不可用。先在启动环境中修改或移除覆盖项，再重启项目；网页不会声称已删除仍由环境变量提供的密钥。

保存仅检查格式，不代表密钥有效；连接测试只验证当时的接口连通性与 JSON 回复，不保证模型棋力或长期稳定性。已有对局在下一次在线请求时读取新配置，无需重新开局，已用请求次数不会因修改而清零。删除后不再发起新的在线请求，改用本地合法方案；已发起的请求可能继续完成和计费。重新保存有效配置后可恢复在线选招。

高级用户仍可编辑本地文件，或复制 `config/llm.example.json` 作为模板。默认内容：

   ```json
   {
     "api_key": "",
     "base_url": "https://api.deepseek.com",
     "model": "deepseek-flash",
     "timeout_seconds": 8,
     "max_requests": 80
   }
   ```

## 费用与响应

- 默认模型是 `deepseek-flash`，通过官方 Chat Completions API 调用，关闭思考模式，仅返回方案编号。模型和价格可能调整，以 [官方价格](https://api-docs.deepseek.com/quick_start/pricing/) 为准。
- 每个 AI 回合最多发送一次请求，不自动重试；仅有一个候选时直接采用，不付费请求。
- 每次最多提供 12 个完整合法方案、24 张相关棋盘；局面内容超过 24,000 个 ASCII 字符时直接使用本地方案。输出上限 96 tokens，不发送整份存档和身份信息。
- 默认等待 API 8 秒，可设置 1–15 秒。达到网络等待上限、断网、限流、密钥无效或模型回复无效时，页面说明原因，并使用已有的本地合法方案。迟到的网络结果不会再次走棋。
- 默认每局最多 80 次请求，可设置 1–200。达到上限后使用本地方案。重新开始或载入对局会重置次数，这不是账户总消费上限；如需硬性金额限制，请在服务商账户另设额度。
- 右侧显示请求次数与本回合来源。累计输入、输出 tokens 由接口返回，包含已收到的无效选招回复；超时请求仍可能被服务商计费，其迟到用量无法保证计入本地统计。账单以服务商为准。

例如，假设一次请求使用 3,000 输入 tokens、96 输出 tokens，40 次调用费用为 `0.12 × 输入单价 + 0.00384 × 输出单价`（单价单位为每百万 tokens）。这只是计算示例；分支多时输入会增加，缓存与服务商实际计费另计。

本地候选搜索默认预算 2 秒，网络等待独立限时；走法复核、终局判断和序列化另需时间，因此不能把 8 秒理解为整个 AI 回合的耗时保证。前端对在线 AI 使用 25 秒请求期限，超时后沿用既有状态同步，不重复提交回合。普通走子、合法落点查询、双人联机不调用 LLM。

## 引擎与模型各自负责什么

引擎生成完整回合候选，保证所有必须推进的棋盘和王安全检查都通过。模型只选候选编号；真实引擎在落子前再次校验整个回合，并只提交一次。跨时间线移动、历史分支和多棋盘回合继续遵守现有规则。

候选搜索有数量与时间限制，模型看到的不是全部可能走法，也不会穷举未来。若本地搜索未能找到完整合法方案，则明确显示规划失败，保留重试入口；不会让模型生成未经校验的走法，也不会把搜索超时判为将杀。

本地回退使用搜索排序中的完整合法候选，并优先避开第三次重复局面；不等同于困难 AI 的深度搜索。当前没有实测模型棋力提升，也没有真实 DeepSeek 账户的计费和延迟验证。

## 其他兼容接口

可修改 `base_url` 和 `model`，接口需要支持 `/chat/completions`、`response_format: {"type":"json_object"}`、`max_tokens` 以及标准 `choices` 回复。`base_url` 填接口根地址（例如带 `/v1` 的根），不要重复填写 `/chat/completions`。只对官方 DeepSeek 地址自动传递关闭思考参数；其他模型需自行确认其默认推理行为与计费。

远程接口要求 HTTPS；本机模型可使用 `http://127.0.0.1:端口/v1` 等回环地址，免鉴权的本机服务在 `api_key` 填一个非空占位值。本机推理软件、模型下载和显卡需求需自行准备，不随游戏安装。

也可使用环境变量覆盖 JSON：`FIVE_D_CHESS_LLM_API_KEY`、`FIVE_D_CHESS_LLM_BASE_URL`、`FIVE_D_CHESS_LLM_MODEL`、`FIVE_D_CHESS_LLM_TIMEOUT_SECONDS`、`FIVE_D_CHESS_LLM_MAX_REQUESTS`。有任何环境变量覆盖时，网页设置为只读并说明原因，避免出现“已保存但不生效”；需在启动环境修改，或移除覆盖并重启后再使用网页编辑。无需安装额外 Python SDK。

接口参考：[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/) · [思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。
