# 游玩指南

[文档目录](../README.md) · [下载与启动](../../使用说明.txt)

## 选择模式

| 玩法 | 如何开始 |
| --- | --- |
| 人机对弈 | 启动“本地”，在主页选择人机与难度 |
| 同屏双人 | 启动“本地”，在同一浏览器选择同屏双人，轮流操作 |
| 局域网联机 | 房主启动“本地”，双方打开启动窗口中的局域网网址 |
| 异地联机 | 房主启动“远程”，双方打开生成的公网网址 |

联机时房主创建在线房间，再复制邀请链接给对方。只有房主需要项目和启动窗口，加入者使用浏览器。房间码不能独立查找另一台电脑的网站，必须打开房主的同一个网址。

## 从教程开始

第一次打开主页会显示教程，也可以点击菜单的“第一次玩？从这里开始”或对局内“新手教程”。三课依次练习普通走子、跨时间线移动和回到历史生成分支。

每课按“选棋子 → 点落点 → 提交行动”完成。教程使用独立局面，不会改动正在进行的本地或在线对局，关闭后可随时重新进入。

## 完成一个回合

1. 查看标为必须推进的红框棋盘。
2. 选中当前可操作的棋子，点击高亮的合法落点；目标可能位于另一张棋盘。
3. 跨线或回到过去后，查看高亮的后继棋盘；原历史棋盘会保留。
4. 推进所有必须行动的棋盘，并保护所有王，再点击“提交行动”交给对手。

一个行动可以包含多个走子，落下一个棋子不一定立即换人。如果不能提交，查看行动面板列出的原因。棋盘可以缩放，并可定位到当前时刻。

往返提醒表示最近的完整前沿配置重复出现，不会自动判和，也不会禁止合法走子。精确规则见 [规则与引擎](../reference/ENGINE.md)。

## 断线与停止

- 联机期间保持房主电脑、启动窗口和双方页面运行。
- 短暂断线时保留原页面等待自动重试；刷新时使用同一浏览器、同一网址恢复身份。
- 离线 8 秒后暂停操作，额外保留 10 分钟供重连。正常活动会持续续期。
- 停止服务、主动关闭房间或超过保留期后，已经清理的在线棋局无法恢复。
- 结束时在启动窗口按 **Ctrl+C**。远程重启通常会更换网址，应重新邀请。

启动或联机故障见 [使用说明](../../使用说明.txt) 和 [联机排查](P2P_CLOUDFLARE.md)。
