# 游玩指南

[文档目录](../README.md) · [下载与启动](../../使用说明.txt)

## 选择模式

| 玩法 | 如何开始 |
| --- | --- |
| 人机对弈 | 启动“本地”，在主页选择人机与难度 |
| 同屏双人 | 启动“本地”，在同一浏览器选择同屏双人，轮流操作 |
| 局域网联机 | 房主启动“本地”，双方打开启动窗口中的局域网网址 |
| 异地联机 | 房主启动“远程”，双方打开生成的公网网址 |

联机时房主创建在线房间，再复制邀请链接给对方。只有房主需要项目和启动窗口，加入者使用浏览器。房间码不能独立查找另一台电脑的网站，必须打开房主的同一个网址。

## 已经会下国际象棋：先看跨棋盘速读

首次进入且没有教程记录时，会显示简明速读；也可随时从主页或对局顶部打开。先看车、象、马的跨盘对照图，再分清「目标是最新棋盘」和「目标是历史棋盘」的结果，最后记住红框与回合提交。打开说明和切换图例不需要请求服务器，也不会改变对局。

点击「亲手试这一步」会直接进入对应棋子的独立互动练习；「试一次回到过去」会进入历史分支练习。其他棋子与常见疑问放在可展开的补充说明里。文字版见 [跨棋盘快速上手](CROSS_BOARD_QUICKSTART.md)。

## 需要从基础开始：完整互动教程

主页的“完整 13 课互动教程”或对局内“新手教程”保留完整课程，分为四阶段：

1. **认识规则**：与普通国际象棋、中国象棋的区别；读懂格子、时间 T、时间线 L、白黑阶段与历史棋盘。
2. **基础操作**：兵的第一手、六种棋子速查、马跳子；推进两张红框棋盘后显式提交。
3. **时空移动**：车跨线、返回历史生成分支、象和马的多维走法、兵的前进与吃子方向。
4. **准备实战**：当前时刻与非活动线、王安全、独立完成多棋盘行动。

阅读课有理解问答，操作课需要先走子并提交，再回答问题。答错会解释原因；可以重练、查看提示或撤回练习一步。最后一课不标出出发点，允许自行决定两张棋盘的顺序，以及兵走一格或两格。

课程目录可以跳转复习；本浏览器会保存已完成课程和当前章节，刷新后从本课开头继续。只有完成全部练习和问答才会显示全部完成。浏览器存储不可用时仍可学习，但不能跨刷新保存进度。

教程使用独立局面，不会改动正在进行的本地或在线对局。练习只开放本课走法，正式对局显示全部合法落点；练习中的撤回也不会撤销真实对局。

## 完成一个回合

1. 查看标为必须推进的红框棋盘。
2. 选中当前可操作的棋子，点击高亮的合法落点；目标可能位于另一张棋盘。
3. 跨线或回到过去后，查看高亮的后继棋盘；原历史棋盘会保留。
4. 推进所有必须行动的棋盘，并保护所有王，再点击“提交行动”交给对手。

一个行动可以包含多个走子，落下一个棋子不一定立即换人。如果不能提交，查看行动面板列出的原因。棋盘可以缩放，并可定位到当前时刻。

往返提醒表示最近的完整前沿配置重复出现，不会自动判和，也不会禁止合法走子。精确规则见 [规则与引擎](../reference/ENGINE.md)。

## 断线与停止

- 联机期间保持房主电脑、启动窗口和双方页面运行。
- 短暂断线时保留原页面等待自动重试；刷新时使用同一浏览器、同一网址恢复身份。
- 离线 8 秒后暂停操作，额外保留 10 分钟供重连。正常活动会持续续期。
- 停止服务、主动关闭房间或超过保留期后，已经清理的在线棋局无法恢复。
- 结束时在启动窗口按 **Ctrl+C**。远程重启通常会更换网址，应重新邀请。

启动或联机故障见 [使用说明](../../使用说明.txt) 和 [联机排查](P2P_CLOUDFLARE.md)。
